# Custom 3D models

Every model in `models/custom/` is generated by these scripts in headless Blender (the `bpy` Python package, Blender 5.2), no manual modelling:

| Script | Makes |
|---|---|
| `ship.py` | the Serpent galleon (walkable deck layout used by the harbor) |
| `chars2.py` | the crew and townsfolk in a chunky cartoon style, rigged with idle / walk / emote / wave / laugh animations and a jaw bone for lip sync |
| `nature.py` | palms, rocks, bushes, flowers, ferns, driftwood |
| `harbor.py` | market stalls, lighthouse and props |
| `harbor2.py` | crooked timber houses with shingle roofs, the walk-in tavern, stone well, cauldron, treasure chests, message bottle, fishing spot, cannon targets, jungle plants, cliff and cave |

```
pip install bpy==5.2.3
python ship.py && python chars2.py && python nature.py && python harbor.py && python harbor2.py
```

The scripts write `.glb` files to `/home/claude/work/out/` (change `OUT` / the export paths to suit). The game loads them from `models/custom/` renamed to `.glb.wasm`, so every static host serves them.
