# Custom 3D models

Every model in `models/custom/` is generated by these scripts in headless Blender (the `bpy` Python package, Blender 5.2), no manual modelling:

| Script | Makes |
|---|---|
| `ship.py` | the Serpent galleon (walkable deck layout used by the harbor) |
| `chars.py` | the crew and townsfolk, rigged with idle / walk / emote / wave animations and a jaw bone for lip sync |
| `nature.py` | palms, rocks, bushes, flowers, ferns, driftwood |
| `harbor.py` | market stalls, houses, tavern, lighthouse and props |

```
pip install bpy==5.2.3
python ship.py && python chars.py && python nature.py && python harbor.py
```

The scripts write `.glb` files to `/home/claude/work/out/` (change `OUT` / the export paths to suit). The game loads them from `models/custom/` renamed to `.glb.wasm`, so every static host serves them.
